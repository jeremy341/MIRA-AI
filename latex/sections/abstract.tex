\section*{Projektüberblick}
\addcontentsline{toc}{section}{Projektüberblick}
Die manuelle Sortierung von Recyclingmaterialien ist zeitaufwändig, kostenintensiv und fehleranfällig. Das Projekt \mira (Machine Intelligence for Recycling Automation) untersucht, wie moderne Deep-Learning-Verfahren zur dezentralen Wertstoffsortierung auf ressourcenbeschränkter Edge-Hardware eingesetzt werden können. Im Rahmen von sechzehn experimentellen Untersuchungen (EXP-001 bis EXP-016) wurde ein System entwickelt, das von einer einfachen Bildklassifizierung mit 4 Klassen (MobileNetV2) zu einer komplexen Multi-Objekt-Erkennung mit 5 Klassen (YOLO11n) skaliert wurde. Die Methode umfasst systematischen Architekturvergleich, Post-Training-Quantisierung auf INT8-Präzision und gezielte Datenfusion aus TACO, TrashNet und Roboflow-Datensätzen. Das fine-tuned MobileNetV2 erreichte \SI{87.42}{\percent} Genauigkeit in der Klassifikation, während das YOLO11n-Detektionsmodell eine mAP50 von \SI{60.7}{\percent} erzielte. Durch Post-Training-Quantisierung konnte das Modell um den Faktor 9 auf \SI{2.61}{\mega\byte} (Klassifikation) beziehungsweise \SI{2.90}{\mega\byte} (Detektion) komprimiert werden. Mit einer CPU-Inferenzlatenz von \SI{10.32}{\milli\second} (EXP-004) beziehungsweise \SI{46.0}{\milli\second} (EXP-014) beweist die Arbeit die Praxistauglichkeit kostengünstiger Sortiersysteme im Echtzeitbetrieb. Diese Ergebnisse bestätigen, dass Edge-KI-basierte Systeme eine performante Alternative zu teuren industriellen Sortieranlagen darstellen.

\section*{Fachliche Kurzfassung}
\addcontentsline{toc}{section}{Fachliche Kurzfassung}
Die manuelle Sortierung von Recyclingmaterialien ist zeitaufwändig, kostenintensiv und fehleranfällig. Diese Arbeit untersucht im Rahmen des Projekts \emph{\mira}, wie verschiedene tiefe neuronale Netzwerkarchitekturen die automatische Klassifikation und räumliche Lokalisierung von Wertstoffen auf ressourcenbeschränkten Edge-Geräten beeinflussen. Dabei wurde in Stage A (Klassifikation) ein vierklassiges System (Glas, Metall, Papier, Plastik) als Machbarkeitsnachweis etabliert, welches in Stage B (Detektion) um eine fünfte Klasse (Restmüll) für praxisnahe Abfallströme erweitert wurde.

Durch einen systematischen Vergleich eines von Grund auf trainierten Convolutional Neural Networks (Scratch-CNN), eines vortrainierten MobileNetV2 mit Transfer Learning (Frozen Base) und eines verfeinerten MobileNetV2 (Fine-Tuning) wurden Klassifikationsgenauigkeit, Inferenzgeschwindigkeit und Modellgröße evaluiert \cite{yosinski2014transferable}. Das fine-tuned MobileNetV2 erreichte eine Validierungsgenauigkeit von \SI{87.42}{\percent} und übertraf das Scratch-CNN um \num{26.42} Prozentpunkte. Zur Optimierung für Edge-Hardware wurde das Keras-Modell mittels Post-Training-Quantisierung auf 8-Bit-Integers (INT8) konvertiert \cite{deng2020model}. Dies reduzierte die Modellgröße um das 9-Fache auf \SI{2.61}{\mega\byte} bei einer durchschnittlichen CPU-Inferenzzeit von nur \SI{10.32}{\milli\second} ohne Genauigkeitsverlust.

Um reale Multi-Objekt-Szenarien abzubilden, wurde das System auf YOLO11n mit 5 Klassen migriert \cite{ultralyticsyolov8}. Ein systematischer Datensatzvergleich (EXP-013 bis EXP-016) über TACO \cite{proenca2020taco}, Stanford TrashNet \cite{yang2016classification} und Roboflow ergab, dass die Kombination TACO+TrashNet+Roboflow (EXP-014) mit \SI{60.7}{\percent} mAP50 das beste generalisierbare Detektionsergebnis liefert. Durch INT8-Quantisierung wurde das Detektionsmodell auf \SI{2.90}{\mega\byte} komprimiert und liefert eine GPU-Inferenzlatenz von \SI{1.8}{\milli\second}. Diese Ergebnisse belegen die Machbarkeit kostengünstiger, echtzeitfähiger und hochpräziser Recycling-Sortiersysteme auf Basis von Edge-KI.
